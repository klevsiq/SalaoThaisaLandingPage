# Salão Thaisa — Landing Page

Landing page do Tha Carolina Hair Studio.

## Estrutura

```
assets/
  css/style.css       — estilos do site
  js/main.js          — scripts (slider, status, animações)
  images/
    gallery/          — fotos dos serviços (image_01 … image_20)
    logos/            — logos de marcas parceiras
index.html            — página principal
```

## Desenvolvimento local

Abra `index.html` diretamente no navegador ou use uma extensão como Live Server no VS Code.
